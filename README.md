# The System v0

The most basic version of The System: a plain green terminal and one agent, The Mainframe,
which can rewrite its own window (`ui/desktop/src/experience/ExperienceCanvas.tsx`).

Run: `run-system.cmd` (Windows, Git Bash) or `./run-system.sh`. First run builds the goose backend.
Reset the canvas: `git restore -- ui/desktop/src/experience`.
